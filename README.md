## 🔬 Research Highlight

<div align="center">

<img src="https://raw.githubusercontent.com/Juha464/Juha464/main/assets/research-pipeline.svg" width="100%" alt="Five progressively complex architectures for brain tumour MRI classification"/>

<br>

<a href="https://github.com/ch-naimul/Undergrad_Thesis"><img src="https://img.shields.io/badge/📄_READ_THE_FULL_STUDY-0B1120?style=for-the-badge&logo=github&logoColor=38BDF8"/></a>

</div>

<br>

Five progressively complex architectures trained end-to-end on **BRISC 2025** with Focal Loss, AdamW, cosine annealing, staged backbone fine-tuning and early stopping — then held to the same bar: does the extra capacity *actually* pay?

<details>
<summary><b>🔍 How it was measured — click to expand</b></summary>

<br>

| Dimension | Setup |
|:--|:--|
| **Task** | 4-class brain tumour MRI classification |
| **Validation** | Stratified 5-fold cross-validation |
| **Optimisation** | Focal Loss · AdamW · cosine annealing · early stopping |
| **Explainability** | Grad-CAM++ · Transformer Attention Rollout · hybrid fusion |
| **XAI metrics** | Insertion / Deletion AUC · confidence-drop |
| **Significance** | Wilcoxon signed-rank test across folds |

**Takeaway:** peak AUC reached 0.9998, but the Wilcoxon test returned p ≥ 0.0625 — the added complexity produced no statistically significant gain. Evidence of **performance saturation** among the evaluated pretrained CNN architectures, not of a better model.

</details>
